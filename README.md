# Hospital Database Management System (SQL)

## Project Overview

A hospital manages a large amount of information related to patients, doctors, medicines, appointments, and prescriptions. Managing all this information properly is important for smooth hospital operations.

In this project, I created a Hospital Database Management System using SQL to organize and manage hospital-related information in a structured way. The project helped me understand how databases store information and how SQL queries can be used to retrieve, update, and analyze records efficiently.

## Tools Used

- MySQL

## Database Details

- **Database Name:** hospital_db
- **Tables:** Doctors, Patients, Medicines, Surgical Items, Appointments, and Prescriptions.

## Key Features

- Created database tables and inserted sample hospital records.
- Modified table structures using `ALTER TABLE`.
- Retrieved, filtered, and sorted records using SQL queries.
- Used aggregate functions such as `COUNT()` and `AVG()` to perform calculations.
- Applied `GROUP BY` and `HAVING` to summarize and analyze records.
- Used SQL joins to retrieve related information from multiple tables.
- Analyzed medicine prices, expiry dates, appointments, and prescriptions.

## What I Learned

While working on this project, I gained practical experience in MySQL and database management. I learned how to create tables, insert records, modify database structures, and retrieve information using different SQL queries.

I also improved my understanding of aggregate functions, grouping, filtering, and joins. This project helped me understand how SQL can be used to manage structured data and handle real-world database requirements.
