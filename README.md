# Hospital Database Management System (SQL)

## Project Overview

Hospitals handle a lot of information related to doctors, patients, medicines, appointments, and prescriptions. Managing all these records in an organized way is important for the smooth functioning of a hospital.

In this project, I created a Hospital Database Management System using MySQL. The main purpose was to store hospital-related information in different tables and practice retrieving and managing records using SQL queries.

## Tools and Technologies Used

- MySQL

## Database Details

**Database Name:** `hospital_db`

The database contains six main tables:

- **Doctors:** Stores doctor names, specializations, experience, and contact details.
- **Patients:** Stores patient names, ages, gender, and city.
- **Medicines:** Contains medicine names, categories, prices, and expiry dates.
- **Surgical:** Stores surgical item names, types, costs, and stock quantities.
- **Appointments:** Maintains patient appointments, doctor details, dates, and status.
- **Prescriptions:** Stores prescription details related to patients, doctors, and medicines.

## Work Performed

I started by creating the `hospital_db` database and setting up six tables with their required columns. After creating the tables, I inserted sample records to practice different database operations.

I also modified the database structure using `ALTER TABLE`. This included adding new columns, renaming columns, changing data types, dropping a column, and renaming a table.

After preparing the database, I practiced different SQL queries to retrieve and analyze information. I used filtering, sorting, pattern matching, aggregate functions, and grouping to get the required results.

## Key Features

- Created a hospital database with six tables.
- Inserted sample records into all tables.
- Modified table structures using `ALTER TABLE`.
- Retrieved information using `SELECT` queries.
- Filtered records using `WHERE`, `BETWEEN`, and `LIKE`.
- Sorted records using `ORDER BY`.
- Used `LIMIT` to display specific records.
- Applied aggregate functions such as `COUNT()` and `AVG()`.
- Used `GROUP BY` and `HAVING` to summarize information.
- Practiced SQL joins to retrieve related information from multiple tables.
- Analyzed doctor specializations, patient records, medicine prices, expiry dates, appointments, and prescriptions.
